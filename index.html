Automatic GitHub Photo Sync

Drop photos into your GitHub repo & they show up automatically!

How Automatic GitHub Folder Sync Works:
  1. Create a folder named photos inside your GitHub repository.
  2. Upload any of Đạo Thành's photos (.jpg, .png, .webp, .gif) into that photos/ folder on GitHub.
  3. Tip for Captions: Name the file like Sweet_Boba_At_CUHK.jpg and the website automatically turns the filename into a cute caption!
  4. When hosted on GitHub Pages (username.github.io/repo), this website automatically detects your repo and fetches every image in photos/!
