How to Host Server-Side on Vercel

Zero server maintenance — works just like your regular Vercel workflow!

✨ 3-Step Vercel Serverless Setup (Auto-Reads `/photos` Folder):
  1. In your GitHub repo connected to Vercel, create a photos/ folder and drop IMG_6962.JPG (and any new photos) inside it.
  2. Create a file named api/photos.js in your project with the 12-line serverless code below.
  3. Push to GitHub! Vercel automatically runs /api/photos on the server, scans your photos/ folder, and displays every image on the website automatically.
File 1: api/photos.js (Vercel Serverless Function) 
const fs = require('fs');
const path = require('path');

module.exports = (req, res) => {
  const photosDir = path.join(process.cwd(), 'photos');
  if (!fs.existsSync(photosDir)) return res.json({ photos: [] });

  const files = fs.readdirSync(photosDir)
    .filter(f => /\.(jpe?g|png|webp|gif)$/i.test(f));

  const photos = files.map((file, i) => ({
    id: `srv-${i}`,
    url: `/photos/${file}`,
    caption: file.replace(/\.[^/.]+$/, '').replace(/[-_]+/g, ' ') + ' ✨',
    rarity: 'SSR ★ VERCEL'
  }));

  res.status(200).json({ photos });
};
